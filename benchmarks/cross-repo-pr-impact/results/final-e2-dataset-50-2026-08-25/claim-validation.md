# Claim validation

## Supported

- Exactly 50 unique cases satisfy the machine-parsed strict-E2 direction A0 pass, A1 fail, A2 pass; zero cases rely only on the index declaration.
- All 50 point to retained local execution evidence; the four newly added cases additionally retain fresh raw command logs.
- Duplicate module/component observations are collapsed to the causal-relation unit.
- E1 records and the rejected Terser/Preconstruct candidate are absent from the 50-case index.

## Not supported

- A formal leakage-free benchmark score.
- Open-world repository discovery performance.
- Precision, F1, false-positive rate, specificity, or complete-negative-space claims.
- Maintainer adoption for the two Crater repairs marked `external_contributor_unmerged`.
- Blind evaluation or holdout use of the current visible-label split proposal.
- Independence between the generated index and the generator; retained execution evidence, not the generated index, is the arm truth source.
