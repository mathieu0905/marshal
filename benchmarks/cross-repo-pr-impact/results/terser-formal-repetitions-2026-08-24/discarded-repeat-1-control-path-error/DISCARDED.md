# 废弃说明

这轮不能计入正式重复。脚本复制了筛选环境，却遗漏了两个由历史开发安装方式产生的路径事实：

- Preconstruct 的开发入口写死了筛选目录的绝对路径，复制后仍从原目录加载 worker，导致 A1 使用了错误的依赖目录，A1 与 A2 的方向颠倒。正式脚本现会在每个独立目录内重新执行 `yarn preconstruct dev`。
- Angular CLI 实际从 `packages/angular_devkit/build_angular/node_modules/terser` 解析受控依赖；本轮只替换了根目录副本，因此 A0 与 A1 都使用了 4.3.1 的行为。正式脚本现控制并核对实际解析路径。

UI5 A1 的六项失败实际成立，只是初版摘要解析器错误地要求日志同时打印通过项数量。原始日志与汇总表保留，用来说明为何整轮废弃，不能拆出其中正确的仓库结果计数。
